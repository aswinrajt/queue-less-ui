# QueueLess UI

React frontend for QueueLess, a digital queue management app for clinics, salons, service centres, restaurants, and similar businesses.

## Stack

- React 19 + TypeScript
- TanStack Start / Router / Query
- Tailwind CSS + shadcn/ui
- Vite

## Run locally

```sh
npm i
npm run dev
```

Set `VITE_API_URL` to the API, for example `http://localhost:4000/api/v1`.

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run preview` — preview the production build
